# المعمارية الهندسية لمنصة وَعْـد (Waad Platform Architecture)

## 1. نظرة عامة (Overview)
منصة **وَعْـد (Waad)** مبنية على معمارية **Jamstack Edge-First** فائقة السرعة، مصممة لتحمّل آلاف الزوار المتزامنين في أوقات الذروة (ليالي الزفاف والمناسبات) بتكلفة تشغيلية تقترب من الصفر وبأعلى معايير الخصوصية.

## 2. الطبقات المعمارية (System Layers)
1. **طبقة العرض والتوزيع (Edge CDN Layer):**
   - مستضافة عبر **Cloudflare Pages** (مع توافق كامل مع Netlify).
   - يتم تقديم ملفات HTML/CSS/JS الثابتة من أقرب نقطة تواجد (PoP) داخل مصر في أقل من 20ms.
2. **طبقة منطق العميل المعيارية (Modular ES6 Client Layer):**
   - مقسمة وفق مبدأ المسؤولية الواحدة (Single Responsibility Principle) داخل `src/js/`.
   - تشمل: التعقيم الأمني (`security.js`)، توليد البطاقات الرسومية (`card-canvas.js`)، والتوقيت اللحظي (`countdown.js`).
3. **طبقة البيانات السحابية (Serverless Persistence Layer):**
   - تعتمد على **Supabase (PostgreSQL)** عبر واجهة REST API المباشرة المحمية بسياسات `Row Level Security (RLS)`.

## 3. نموذج الخصوصية والأمان (Privacy & Security by Design)
- **عدم تخزين أرقام الهواتف:** لا يتم إرسال أو حفظ أي رقم هاتف خاص بالمعازيم على أي خادم سحابي.
- **الحماية ضد XSS:** جميع المدخلات القادمة من الرابط (`#g=`) أو من حقول الإدخال تمر عبر محرك تعقيم صارم قبل العرض.
- **منع التكرار الذكي:** استخدام `guest_token` محلي لمنع الإرسال المتكرر بالخطأ من نفس الهاتف مع السماح بتسجيل الضيوف الذين يحملون نفس الاسم الثنائي.
