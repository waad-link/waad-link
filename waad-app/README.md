# 💍 منصة وَعْـد | Waad Platform
**الجيل الجديد من دعوات الأفراح والمفاجآت التفاعلية في مصر والشرق الأوسط.**

## ✨ المميزات الرئيسية
- **كارت التشريف الذاتي (Self-Claimed VIP Pass):** يستلم كل ضيف بطاقة دعوة مخصصة باسمه مع إمكانية حفظها كصورة عالية الجودة.
- **خصوصية مطلقة (Zero-Phone Storage):** لا نخزن أرقام هواتف الضيوف على أي خادم.
- **لوحة تحكم لحظية للعريس (`admin.html`):** متابعة أعداد وأسماء الحضور مباشرة مع تصدير كشف Excel/CSV لإدارة القاعة.
- **معمارية فائقة السرعة:** مبنية بمعايير Jamstack ومستضافة عبر Cloudflare Edge.

## 📂 هيكل المشروع
راجع ملف [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) للاطلاع على التفاصيل الهندسية الكاملة.

## 🚀 التشغيل والنشر السحابي
1. قم بإنشاء مشروع على **Supabase** ونفّذ ملف `schema.sql` داخل الـ SQL Editor.
2. ضع `supabaseUrl` و `supabaseKey` داخل ملف `src/js/core/config.js`.
3. اربط المستودع بحساب **Cloudflare Pages** ليتم النشر تلقائياً.
